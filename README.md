# Quantitative Market Trend & Risk Analytics Pipeline

An automated data pipeline and interactive business intelligence dashboard tracking macroeconomic benchmarks (S&P 500 `SPY`, Nasdaq 100 `QQQ`, 20+ Year Treasuries `TLT`, and Gold `GLD`). 

The platform extracts multi-year adjusted daily pricing, persists normalized relational tables in an embedded analytical OLAP database (DuckDB), calculates key portfolio risk metrics (log returns, rolling annualized volatility, rolling Sharpe ratios, and max drawdown), and presents actionable insights via Streamlit and Plotly.

---

## Architecture Overview

```text
[ yfinance API ] 
       │
       ▼ (Extract & Validate)
[ pipeline.py ] ──► [ DuckDB: raw_prices ]
                            │
                            ▼ (Transform & Window Functions)
                     [ analytics.py ] ──► [ DuckDB: processed_analytics & correlation_matrix ]
                                                 │
                                                 ▼ (Interactive Reporting)
                                          [ app.py (Streamlit) ]
```

- **Data Ingestion (`pipeline.py`):** Automated idempotent pipeline handling timezone normalization, schema enforcement, and upsert logic into DuckDB.
- **Quantitative Engine (`analytics.py`):** Computes risk-adjusted performance using vectorized pandas and numpy operations:
  - **Log Returns:** $R_t = \ln(P_t / P_{t-1})$
  - **Annualized Volatility (60-day rolling):** $\sigma_{\text{ann}} = \sigma_{60} \times \sqrt{252}$
  - **Rolling Sharpe Ratio:** $\frac{\overline{R} - R_f}{\sigma} \times \sqrt{252}$ (assumes risk-free rate $R_f = 4.0\%$)
  - **Peak-to-Trough Drawdown:** Tracks downside risk, historical pullbacks, and recovery profiles.
  - **Asset Correlation Matrix:** Pairwise log-return correlation across equity, fixed income, and commodities.
- **Interactive UI (`app.py`):** Executive dashboard featuring top-line KPI cards, comparative growth curves, underwater drawdown charts, rolling Sharpe ratios, and correlation heatmaps.

## Tech Stack

- **Language:** Python 3.9+
- **Data Engineering & Analysis:** Pandas, NumPy
- **Database / Storage:** DuckDB (In-process OLAP SQL database)
- **Visualization & UI:** Streamlit, Plotly
- **Data Ingestion:** Yahoo Finance (`yfinance`)

---

## Key Analytical Insights

1. **Flight to Safety vs. Growth:** Identifies structural decoupling and inverse correlation regimes during market stress points (e.g., treasuries `TLT` vs. tech equities `QQQ`).
2. **Volatility Clustering:** Highlights windows where 60-day rolling volatility spiked past 30% annualized, preceding sharp drawdown events.
3. **Risk-Adjusted Decoupling:** Demonstrates how nominal price appreciation can mask deteriorating Sharpe ratios during elevated rate environments.

## Getting Started

### Prerequisites
- Python 3.9 or higher installed
- Git

### Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/](https://github.com/)<your-username>/market-trend-tracker.git
   cd market-trend-tracker
   ```

2. **Create and activate a virtual environment:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate   # On Windows: venv\Scripts\activate
   ```

3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Execute pipeline & quantitative analytics:**
   ```bash
   python pipeline.py
   python analytics.py
   ```

5. **Launch the interactive dashboard:**
   ```bash
   streamlit run app.py
   ```
   The application will automatically open in your default browser at `http://localhost:8501`.
